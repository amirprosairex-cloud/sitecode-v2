# SiteCode — новый сайт

Главная страница студии и 7 демо-сайтов для разных видов бизнеса.

## Как открыть на компьютере

3D-кубики не запускаются, если просто дважды кликнуть по `index.html` (браузер не даёт модулям грузиться с диска). Запустите маленький сервер в этой папке:

```
python -m http.server 5173
```

и откройте http://127.0.0.1:5173

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: тексты, цены, вопросы, контакты |
| `assets/css/main.css` | Стили главной. Цвета и шрифты — в начале файла (`:root`) |
| `assets/js/main.js` | Интро, калькулятор, форма заявки, анимации при прокрутке |
| `assets/js/cubes.js` | 3D-кубики (Three.js): шар, окно сайта, телефон, логотип |
| `assets/img/works/` | Скриншоты демо для раздела «Примеры» |
| `demos/*.html` | 7 демо-сайтов |
| `demos/assets/` | Общие стили и скрипты демо (запись, «до/после», анимации) |

## Что поменять в первую очередь

- **Номер WhatsApp для заявок**: `assets/js/main.js` → `SITE.whatsapp` и `demos/assets/demo.js` → `SITECODE_WA`. Сейчас стоит +7 778 969 73 05.
- **Контакты в подвале и меню**: `index.html` (поиск по номеру телефона).
- **Цены**: `index.html`, раздел «Цены» и калькулятор (атрибуты `value` у вариантов).
- **Шаг «Эскиз бесплатно и до оплаты»** в разделе «Как мы работаем» — это обещание клиенту. Если не готовы его давать, уберите.

## Демо-сайты

На каждом демо внизу есть плашка «Демо от SiteCode — Хочу такой сайт». Заявки в демо никуда не отправляются: после отправки формы показывается, как сообщение придёт владельцу в WhatsApp, и кнопка, которая ведёт в WhatsApp SiteCode.

Фото в демо — бесплатные с Unsplash (подгружаются по ссылкам с images.unsplash.com).

## Публикация

Сайт публикуется через GitHub Pages из ветки `main` этого репозитория. Любые изменения, отправленные в `main`, появляются на сайте через минуту-две.

Как подключить домен sitecode.store:

1. В старом репозитории `SiteCode`: Settings → Pages → удалить свой домен (иначе GitHub не даст подключить его второй раз).
2. В этом репозитории: Settings → Pages → Custom domain → `sitecode.store` → Save, затем включить Enforce HTTPS.
3. В Namecheap: Domain List → Manage → Nameservers → **Namecheap BasicDNS**. Затем Advanced DNS:
   - четыре записи `A` для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - запись `CNAME` для `www`: `amirprosairex-cloud.github.io`.
